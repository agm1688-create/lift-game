# 🛗 搭 Lift 遊戲（多人 3D 網頁遊戲）

## 本機開
```
npm install
npm start        # 或 node server.js
```
打開 http://localhost:3000

## 俾其他人玩（唔使密碼）
將成個資料夾放上任何支援 Node.js 嘅主機（例如 Render、Railway、Fly.io），
啟動指令 `node server.js`，佢會用環境變數 `PORT`。
⚠️ 語音（咪高峰）一定要 **HTTPS** 先用得（localhost 除外）。

## 操作
- 手機：打橫，左下搖桿跑，右下「跳」同「互動」，拖畫面轉鏡頭，雙指縮放
- 電腦：WASD/方向鍵、滑鼠拖動、滾輪縮放、E 互動、空白鍵跳

## 樓層
- 1–100：大廈　101–1000：天空、雲、飛機　1001–10000：大氣層、太空、9800 樓有太空站
- M：地底電梯機房
